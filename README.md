# ai-portfolio

Boss's AI engineer portfolio site. Static HTML plus a `portfolio.json` that is regenerated by `sync.py` from live empire data every 15 minutes.

## Architecture

```
ai-portfolio/
  index.html        single page shell
  style.css         dark terminal aesthetic, Pixelens green accent
  app.js            hydrates the shell from portfolio.json
  portfolio.json    generated, do not hand edit
  sync.py           reads agents dir, brain map, FOREMAN data, writes portfolio.json
  deploy/
    com.boss.ai-portfolio-sync.plist   launchd agent that runs sync.py every 15 min
    install.sh                          one shot installer for the agent
    uninstall.sh                        one shot remover
  .github/workflows/
    deploy.yml      GitHub Pages auto deploy on push and every 30 min cron
```

## Local preview

The launch.json entry name is `ai-portfolio` on port 8850. From a Claude Code session, `preview_start` with that name. Or run directly:

```
python3 -m http.server 8850 --directory /Users/macbookair/Claude/ai-portfolio
```

## Refresh data

```
python3 /Users/macbookair/Claude/ai-portfolio/sync.py
```

Writes `portfolio.json` with the current agent count, brain map state, CITADEL rampart status, and shipped systems.

## Auto refresh

```
bash /Users/macbookair/Claude/ai-portfolio/deploy/install.sh
```

Loads the launchd agent `com.boss.ai-portfolio-sync`. Logs land in `deploy/sync.out` and `deploy/sync.err`.

To remove:

```
bash /Users/macbookair/Claude/ai-portfolio/deploy/uninstall.sh
```

## Deploy to GitHub Pages

1. Create a new GitHub repo, push this directory as `main`.
2. In the repo, Settings, Pages, set Source to GitHub Actions.
3. The included workflow deploys on every push to `main` and on a 30 minute cron.

The cron runs `sync.py` inside the runner. Since `sync.py` reads local empire files, the cron run falls back to the committed `portfolio.json`. For true live data, run the launchd agent locally and commit `portfolio.json` regularly via a separate cron, or wire a webhook.
